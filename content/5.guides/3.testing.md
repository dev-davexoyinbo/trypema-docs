## Local tests only (no Redis)

```bash [Terminal]
cargo test --no-default-features
```

## All tests (including Redis)

Requires a running Redis instance.

```bash [Terminal]
make test-redis
```

Or point to an existing Redis:

```bash [Terminal]
REDIS_URL=redis://127.0.0.1:6379 cargo test
```

## Notes

- The Redis provider requires Redis >= 6.2.
- Redis tests typically need Docker (if you use the provided compose harness).
