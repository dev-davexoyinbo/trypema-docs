## Local tests only (no Redis)

```bash [Terminal]
cargo test
```

This is useful if you want to validate local-only behavior quickly or if you don't have Redis available.

## All tests (including Redis)

Requires a running Redis instance.

If you're running tests directly (without the Makefile harness), enable a Redis feature:

```bash [Terminal]
cargo test --features redis-tokio
```

```bash [Terminal]
make test-redis
```

Or point to an existing Redis:

```bash [Terminal]
REDIS_URL=redis://127.0.0.1:6379 cargo test
```

## Run a subset

```bash [Terminal]
# One test file
cargo test --test test_absolute_local_rate_limiter

# One test by name
cargo test test_cleanup_removes_stale_keys

# Show output
cargo test -- --nocapture
```

## Debugging

```bash [Terminal]
RUST_LOG=debug cargo test -- --nocapture
```

## Notes

The Redis provider requires Redis >= 6.2. If you use the provided compose harness, Redis tests typically require Docker.
