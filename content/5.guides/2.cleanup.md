Trypema does lazy eviction during normal operations, but keys can still accumulate.

Use the cleanup loop to proactively evict stale keys:

```rust
use std::sync::Arc;
use trypema::RateLimiter;

fn start(rl: Arc<RateLimiter>) {
    rl.run_cleanup_loop();
}
```

::note
The cleanup loop keeps only a `Weak` reference to the `RateLimiter`. Dropping all `Arc<RateLimiter>` references stops cleanup automatically.
::

## Redis caveat

Redis script-level cleanup is lazy. Depending on workload and key cardinality, you may still want external Redis key management.
