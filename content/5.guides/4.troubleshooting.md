## Redis tests fail with connection refused

Check:

- Redis is running and reachable
- `REDIS_URL` points to the right host/port

## Memory usage grows over time

Check:

- key cardinality
- whether `run_cleanup_loop()` is enabled (local provider)
- whether you need external Redis key cleanup (Redis provider)
