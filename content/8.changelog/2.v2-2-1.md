**Status:** Released · October 10, 2026

Version 2.2.1 corrects Redis script failures for large key sets and for keys with many buckets.

## Changed

- Redis and hybrid stale-state cleanup removes stale keys in batches of 500. The pass continues
  until no key that was stale at its start stays. The Redis `clear()` uses the same batches.
- A cleanup pass runs the absolute cleanup and the suppressed cleanup, also when one of them
  fails. Before, a failure of the absolute cleanup stopped the pass.

## Fixed

- Cleanup and the Redis `clear()` no longer fail with `too many results to unpack` when
  approximately 1,600 absolute keys or 1,143 suppressed keys are stale together.
- `inc`, `get`, `delete`, `set_if`, and `set_if_preserve_history` no longer fail with that error
  for a key that has 8,000 or more expired buckets.

See [Troubleshooting](/guides/troubleshooting#redis-reports-too-many-results-to-unpack).
