All strategies return a `RateLimitDecision`:

- `Allowed`: admitted and recorded
- `Rejected { retry_after_ms, remaining_after_waiting, .. }`: denied and not recorded
- `Suppressed { suppression_factor, is_allowed }`: suppressed strategy only

::warning
If you use the suppressed strategy, always treat `is_allowed` as the admission signal.
::

```rust
use trypema::RateLimitDecision;

match decision {
    RateLimitDecision::Allowed => {}
    RateLimitDecision::Rejected { retry_after_ms, .. } => { let _ = retry_after_ms; }
    RateLimitDecision::Suppressed { is_allowed, .. } => {
        if is_allowed { /* proceed */ } else { /* stop */ }
    }
}
```
