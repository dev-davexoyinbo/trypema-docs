Trypema's main entry point is `RateLimiter`.

## Core types

- `RateLimiter`
- `RateLimiterOptions`
- `RateLimit`
- `RateLimitDecision`
- `WindowSizeSeconds`
- `RateGroupSizeMs`
- `HardLimitFactor`

## Providers

- Local: `rl.local()`
- Redis: `rl.redis()` (requires `redis-tokio` or `redis-smol`)
