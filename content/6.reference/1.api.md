Trypema's main entry point is `RateLimiter`.

It is designed to be created once and shared (usually via `Arc<RateLimiter>`).

## Core types

Core types include `RateLimiter`, `RateLimiterOptions`, `RateLimit`, `RateLimitDecision`, `WindowSizeSeconds`, `RateGroupSizeMs`, `HardLimitFactor`, and `SuppressionFactorCacheMs`.

`SuppressionFactorCacheMs` is a validated newtype used by the suppressed strategy to cache suppression-factor computations. `SuppressionFactorCacheMs::try_from(value)` fails if `value == 0`. Default is `100ms`.

## Entry points

### Create

```rust
use trypema::{HardLimitFactor, RateGroupSizeMs, RateLimiter, RateLimiterOptions, SuppressionFactorCacheMs, WindowSizeSeconds};
use trypema::local::LocalRateLimiterOptions;

let rl = RateLimiter::new(RateLimiterOptions {
    local: LocalRateLimiterOptions {
        window_size_seconds: WindowSizeSeconds::try_from(60).unwrap(),
        rate_group_size_ms: RateGroupSizeMs::try_from(10).unwrap(),
        hard_limit_factor: HardLimitFactor::try_from(1.5).unwrap(),
        suppression_factor_cache_ms: SuppressionFactorCacheMs::default(),
    },
});

let _ = rl;
```

## Providers

Use `rl.local()` for in-process limiting. Use `rl.redis()` for distributed limiting (requires `redis-tokio` or `redis-smol`).

## Strategies

| Strategy | Local | Redis |
| --- | --- | --- |
| Absolute | `rl.local().absolute()` | `rl.redis().absolute()` |
| Suppressed | `rl.local().suppressed()` | `rl.redis().suppressed()` |

## Common methods

Use `inc(key, rate_limit, count)` to check admission and record the increment if admitted. Use `is_allowed(key)` for a read-only admission check (absolute strategy).

## Errors

Trypema returns `TrypemaError` for fallible operations (primarily Redis-backed calls):

Common variants include `TrypemaError::RedisError`, `TrypemaError::InvalidRedisKey`, and `TrypemaError::UnexpectedRedisScriptResult`.
