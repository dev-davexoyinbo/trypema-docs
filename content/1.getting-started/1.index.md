Trypema is a Rust rate limiting library supporting both in-process limiting and Redis-backed distributed limiting.

These docs target Trypema `v1.0`.

## What you get

- Providers: local (in-process) and Redis (distributed)
- Strategies: absolute (strict) and suppressed (probabilistic suppression near capacity)
- Best-effort hints on rejection: `retry_after_ms` and `remaining_after_waiting`

::note
Trypema is best-effort under concurrency. In high contention, multiple callers can observe "allowed" at the same time and temporarily overshoot the target rate.
::

## Where to start

- If you want predictable rejection: start with the absolute strategy.
- If you want graceful degradation: use the suppressed strategy.
- If you run more than one instance: use the Redis provider.
