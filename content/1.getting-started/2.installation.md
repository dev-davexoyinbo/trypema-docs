## Crate version

These docs assume Trypema `v1.0`.

## Local-only (no Redis)

```toml [Cargo.toml]
[dependencies]
trypema = { version = "1.0", default-features = false }
```

## Redis provider (Tokio)

```toml [Cargo.toml]
[dependencies]
trypema = { version = "1.0", features = ["redis-tokio"] }
redis = { version = "1", features = ["aio", "tokio-comp", "connection-manager"] }
tokio = { version = "1", features = ["full"] }
```

## Redis provider (Smol)

```toml [Cargo.toml]
[dependencies]
trypema = { version = "1.0", default-features = false, features = ["redis-smol"] }
redis = { version = "1", features = ["aio", "smol-comp", "connection-manager"] }
smol = "2"
```
